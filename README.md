# السفير | AL SAFEER

مستودع مستقل لنظام السفير، المستهدف نشره على `safeer.dropcodejo.com` باستخدام Coolify.

## مصدر النظام
نظام العزوة (أبشر شمال) هو المرجع الوظيفي. يجب التأكد من مطابقة إصدار التشغيل الحالي قبل نقل الكود.

## ضوابط النقل
- لا تربط السفير بقاعدة بيانات العزوة أو Redis الخاص بها أو جلسة واتساب العزوة.
- استخدم PostgreSQL وRedis وجلسة واتساب وبيانات اعتماد مستقلة.
- لا تنسخ أرصدة أو بيانات كباتن العزوة إلى السفير دون طلب صريح.
- لا ترفع مفاتيح API أو كلمات مرور أو ملفات `.env` إلى GitHub.
- هوية السفير: كحلي وبرتقالي، مع الشعار المعتمد.

> هذا المستودع في مرحلة التهيئة، وليس جاهزًا للنشر بعد.
