# السفير | AL SAFEER

نظام السفير يعمل كمشروع مستقل على `https://safeer.dropcodejo.com` عبر Coolify.

## التشغيل
- الخادم: Node.js 22 + Fastify.
- قاعدة البيانات: PostgreSQL، مع Redis لطوابير الجرد.
- نقطة التشغيل: `npm start` (`server.js`).
- اختبارات المشروع: `npm test`؛ وفحوصات GitHub Actions على طلبات الدمج.
- واجهة الكابتن: `/captain`، والمحاسب: `/accountant`، وبوابة الأكواد: `/recharge-portal/`.

## عزل البيانات (مهم)
- السفير والعزوة **نظامان مستقلان**، حتى عندما تتشابه الملفات.
- لا تشارك قاعدة بيانات PostgreSQL أو Redis أو جلسات واتساب أو مفاتيح النظام بينهما.
- لا تنقل أرصدة أو بيانات كباتن من مشروع لآخر إلا بعملية ترحيل مقصودة ومراجعة.
- لا تضف ملفات `.env` أو مفاتيح API أو كلمات مرور إلى المستودع.
- الشعار الرسمي: `assets/safeer-official-logo.png`، والهوية كحلي وبرتقالي.

## مبدأ الصيانة
- اختبر على فرع مستقل قبل دمج أي تحديث في `main`.
- لا تحذف مسارات أو بيانات محاسبية/أرشيفية لمجرد أنها مسماة legacy.
- واجهات النقل القديم قد تكون معطلة عمدًا؛ افحص مراجعها قبل تغييرها.
